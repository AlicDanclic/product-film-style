# 叙事结构

风格解决「看起来像什么」，结构解决「按什么顺序讲」。结构错了，画面再干净也留不住人。

## 先分清两种片子

| | 主片（产品是什么） | 对比片 / 更新片（这版改了什么） |
|---|---|---|
| 时长 | 90–150 秒 | 45–80 秒 |
| 观众 | 第一次见到产品的人 | 已经用过旧版的人 |
| 结构 | 问题 → 能力 → 证据 → 主张 | 直接摆改动，只有一处左右对照 |
| 段长 | 9–12 秒/段 | 8–10 秒/段 |
| 切点 | 可以「从背景长出来」，因为背景连续 | 必须落在已有内容上，快切空白一眼就看出闪 |
| 允许的解释量 | 略多，需要建立认知 | 极少，观众已经知道背景 |

不要拿主片的节奏做更新片，也不要拿更新片的密度做主片。

## 主片骨架

九段，缺段会让人看不懂或者不想看：

1. **品牌开场** —— 标记 + 名称 + 产品定位，不解释
2. **界面首亮相** —— 完整窗口悬浮入场，让观众先看到「这东西长什么样」
3. **痛点** —— 三个具体麻烦，压出一句主张
4. **核心能力 1** —— 最能打的那个功能，演示而非罗列
5. **能力总览** —— 一眼看全的网格（这**是唯一**允许用网格的地方）
6. **核心能力 2** —— 交互深度，拖拽 / 绘制 / 连线这类
7. **架构 / 信任** —— 数据在哪、怎么同步、要不要联网
8. **平台** —— 桌面 + 移动并排，证明不是网页套壳
9. **总结 + 落版** —— 特性 pill 收束，然后三行落版

段落之间硬切。全片**只允许一处**「左右对照」，放在最需要说服人的地方；每段都对比等于每段都没讲清。

### 时长怎么分

- 总时长先定，再按 9 秒/段估段数：120 秒 ≈ 13 段，90 秒 ≈ 10 段
- 交互演示段可以给到 10–12 秒，因为观众要看清动作；陈述段 8–9 秒足够
- 开场和落版各 130–150 帧（4.3–5 秒），不要太长，观众没有耐心等
- **不要靠拉长段落解决「没讲清」**，那是分镜没拆对

## 对比片骨架

```
开场 150 帧（品牌标记 + 版本号 A → B，不加副标题）
  ↓ 硬切
第 1 段 240–260 帧
  ↓ 硬切
第 2 段 …
  ↓ …
落版 130 帧（版本已发布 + 一句人话 + 授权/价格 + URL）
```

- 段数 4–6，超过 6 段观众记不住
- 每段**只讲一个改动**。一个改动如果牵涉两套独立配置（比如「字段」和「视图」各管一摊），必须拆成两段分别讲——合并着讲会让人以为关字段等于关视图
- 段间全硬切，只有进落版时用一次淡出
- 全片字幕 6 行以内

## 顺序的三条原则

**1. 先完整、后收窄**

要表达「默认值变了」，正确顺序是：先给完整态（15 个字段全开），再逐个关掉收窄到 3 个。反过来（先给 3 个、再补到 15 个）观众会理解成「功能变多了」。

**2. 减法单独成段，混进升级里讲**

删掉的功能（图例、里程碑线、逾期标记）不要含糊成「优化」。单独用一句「这一版都没有」说清，否则老用户装上新版会以为是 bug。

**3. 对比放在最需要说服的那一刻**

一支片子里只有一处左右对照时，观众的注意力会全部集中在那里。把它放在「如果这点不成立，整个片子就不成立」的位置。

## 开场与落版的固定范式

**开场**（沿用同一套字标动效，跨片子复用）：

1. 品牌标记 spring 入场
2. 产品名逐字符升起，其中一段走品牌渐变
3. 版本号 / 定位句
4. 到此为止——**不加副标题、不加说明行、不加「让我们开始」**

**落版**（三行封顶）：

```
一句结论（状态 + 一句人话）
授权 / 价格
带图标的 URL（等宽、弱化色）
```

不要放二维码、五个社交图标、Slogan 排比、感谢观看。

## 信息点密度

一分钟最多承载 6–8 个信息点。超了观众只能记住最后一个。

估法：数一遍全片「观众需要记住的新名词 / 新数字」有多少个，除以分钟数。超过 8 就该删段或把两个点合并成一个演示。
