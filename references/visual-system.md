# 视觉系统具体数值

本文是 SKILL.md 定律一、四、五、六的落地参数。数值来自已交付的 1920×1080 产品片，做同风格新片时可直接沿用；做 1080p 以外的画幅按比例缩放，比例关系（字号 / 画布高 ≈ 0.078）保持不变。

## 画布与安全区

| 项 | 值 |
|---|---|
| 画布 | 1920 × 1080 |
| 帧率 | 30 fps |
| 主内容横向内边距 | 240 px（左右各） |
| 产品窗口 | 1480 × 840，圆角 18 |
| 窗口 chrome 高度 | 42 |
| 窗口侧栏宽度 | 218 |
| 底部字幕带基线 `CAPTION_TOP` | 966 |
| 卡片下沿安全线 | ≤ 890（压到字幕带会撞字） |
| 对照类双面板顶 `DUAL_TOP` | 222 |

**安全区口诀**：字幕带是硬边界，任何卡片、面板、图表的下沿都不能越过 890。写分镜时就按 890 反推内容高度，不要画完再挤。

## 色彩

| 角色 | 值 | 用法 |
|---|---|---|
| 正文近黑 `ink` | `#17152B` | 标题、大字 |
| 正文 `text` | `#111827` | 主要内容 |
| 次要 `secondary` | `#4B5563` | 说明、标签 |
| 弱化 `muted` | `#9CA3AF` | 占位、禁用 |
| 品牌主色 `indigo` | `#4F46E5` | 唯一强调色 |
| 品牌柔色 `indigoSoft` | `#6366F1` | 次级强调、悬停 |
| 渐变中段 `violet` | `#8B5CF6` | 关键词渐变起点 |
| 渐变末端 `pink` | `#EC4899` | 关键词渐变终点 |
| 面 `surface` | `#F3F4F6` | 卡片底、输入框 |
| 侧栏 `sidebar` | `#F9FAFB` | 应用侧栏 |
| 描边 `border` | `#E5E7EB` | 分隔线、卡片边 |
| 语义 · 完成 | `#10B981` | 仅状态 |
| 语义 · 进行中 | `#F59E0B` | 仅状态 |
| 语义 · 逾期 | `#EF4444` | 仅状态 |
| 语义 · 信息 | `#3B82F6` | 仅状态 |

两条渐变，别混用：

```
品牌渐变      linear-gradient(105deg, #4F46E5 0%, #8B5CF6 48%, #EC4899 100%)
品牌渐变(浅)  linear-gradient(135deg, #EEF2FF 0%, #F5F3FF 52%, #FDF2F8 100%)
```

- **关键词渐变只给词，不给句**。做法：`background-clip: text` + `color: transparent`，作用在一个 `<span>` 上，一句话里最多两处。
- 语义色不许拿来当装饰。画面里出现绿色，观众就应该理解成「完成」，不能只是「好看」。

## 字体阶梯

字体栈（西文优先、中文兜底）：

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
"Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif
```

等宽栈（代码、路径、版本号、URL）：

```
"Cascadia Code", "SFMono-Regular", Consolas, "Liberation Mono", monospace
```

| 层级 | 字号 | 字重 | 字距 | 用途 |
|---|---|---|---|---|
| 主张大字 | 84 | 800 | −4 | 一句话观点，全片最多两三处 |
| 场景标题 | 56 | 700 | −2 | 段标题（仅主片用，短片不用） |
| 字幕 | 34 | 700 | −0.5 | 每段底部那一行短语 |
| 面板标题 | 26 | 700 | 0 | 卡片 / 面板头 |
| 正文 | 22 | 500 | 0 | 界面内文字 |
| 注释 | 20 | 500 | 0 | 小字、右下角说明 |
| 等宽元信息 | 22 | 500 | 0 | URL、路径、版本号 |

- 字重只用 500 / 600 / 700 / 800 四档，不要出现 300 细体（投影屏上会糊）。
- 中文不要加 `letter-spacing` 正值；收紧到 −0.5 ~ −4 才有「设计感」。
- 左对齐优先。居中是留给绝对对称的落版画面的。

## 阴影三档

```
窗口  0 44px 100px rgba(55,48,163,.14), 0 12px 30px rgba(55,48,163,.08), 0 0 0 1px rgba(79,70,229,.07)
卡片  0 18px 44px rgba(55,48,163,.10), 0 2px 8px rgba(55,48,163,.05)
胶囊  0 12px 28px rgba(55,48,163,.08), 0 1px 2px rgba(55,48,163,.04)
```

阴影色带紫（`rgba(55,48,163,…)`）而不是纯黑，这样在白底上浮起时不会显脏。**不要用小半径高透明度黑影**，那是 Material 的味道，不是这套风格。

## 背景

三层叠加，全程连续（跨场景不重置），这样硬切时只有内容在变，底不动：

1. 极浅对角渐变：淡紫 → 白 → 淡粉
2. 2–3 个超大半径柔光斑，缓慢漂移（周期 20s 以上，位移不超过 60px）
3. 极淡微尘粒子，透明度 < 0.06

反面：纯 `#FFFFFF` 平铺（会显廉价）、动态网格线、粒子爆炸。

## 动效参数

| 动作 | 做法 |
|---|---|
| 入场 | spring + `translateY 40–70px` + `rotateX 7°`，容器 `perspective(1500px)` |
| 退场 | 上飘 + 透明度降到 10% + 微翻转 |
| 常驻浮动 | 入场 settle 之后启动 `sin` 幅度 ±5px，周期 3–4s |
| 词组 stagger | 12 帧一组，同组内同时出现 |
| 注释行延迟 | 34–46 帧后才淡入，避免切点后只剩一行小字像故障 |
| 曲线 | 全部 `interpolate` 显式 `clamp`，超出时长停在末态 |

退场唯一例外：当退场元素会与后续大字**位置重叠**时（例如痛点卡片正压在主张大字的位置），改成彻底淡到 0，否则会透出底色叠字。

## 时间基准

- 主片 30 fps；界面交互类镜头以 **20 fps 为设计时钟**，在主片里用 `playbackRate = 20/30` 播放，动作时长与 GIF 版完全一致。
- 单段时长按「观众读完画面需要多久」定，经验值 8–12 秒；信息密度高的段可以到 12–15 秒，但**不能靠加长掩盖没讲清**。
- 全片不循环 BGM 段落：短片取曲目前半段即可，避免听到重复。

## 转场与切点

- 段与段之间硬切，切点那一帧必须已经成形。
- 做法是把该段内容的**本地时间轴整体前移**：`useCurrentFrame() + ENTRY`，`ENTRY` 经验值 10 帧；对复杂结构（图谱、表格、节点）用 22–30 帧，因为它们的入场本身就长。
- 不要把入场做成「从零长出来」，而是「从已有状态继续演化」——切点观众看到的是半成品，而不是空白。
- 段尾**不要**额外加淡出；淡出会让下一段的切点变成白屏 0.2–0.3 秒。只有进最终落版时保留一次。

## 字幕带

| 项 | 值 |
|---|---|
| 字号 / 字重 | 34 / 700 |
| 颜色 | `rgba(23,21,43,0.86)` |
| 基线 | 966（距底 114） |
| 淡入淡出 | **无**。跟着硬切一起满、一起消失 |
| 行数 | 1 |

字幕宽度超过 18 个汉字时，先怀疑文案写长了，而不是调小字号。
