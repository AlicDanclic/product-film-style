# 文案与字幕风格

本文是 SKILL.md 定律三的落地细则。核心矛盾：**画面信息密度已经很高，文字必须反过来做减法**。写文案时的心态不是「还漏了什么没讲」，而是「这句能不能整句删掉」。

## 文字分成三级

写任何一屏文字前，先问它属于哪一级。不属于这三级的，全部删掉。

### 一级 · 字幕（每段一行）

- 4–8 个汉字，最多不超过 12 个
- **名词短语**，不带动词尾巴、不带标点、不带编号
- 说完这一段就不用再解释，画面负责剩下的
- 全片字数加起来控制在 6–10 行，多一行都是在替观众判断

| 好 | 差 | 差在哪 |
|---|---|---|
| `任务字段自定义` | `现在你可以自由自定义任务字段了` | 多了主语和语气词 |
| `甘特图绘制` | `全新增加可绘制的甘特图视图` | 「全新增加」「可」是废话 |
| `任务列表拖动排序` | `02 · 任务列表支持按住拖动来改变顺序` | 编号 + 动词 + 解释 |
| `插件跑进 Worker` | `插件执行位置优化：从主线程移入 Worker` | 冒号加解释 |
| `项目视图随意选` | `项目视图简化到只有一个` | 说成了限制，实际是「可选」 |

### 二级 · 标识（允许保留）

这些不是「说明文字」，是**画面里本来就应该有的东西**，画出来是对的：

- 字段名、视图名、按钮名：`标题` `状态` `截止日期` `列表` `看板`
- 函数名、API、路径：`runInWorker()` `DEFAULT_SIMPLE_FIELDS` `.pm`
- 版本号、命令、URL：`0.8.4 → 0.9.10` `npm run build`
- 真实数据：日期、计数、百分比、文件大小
- 计数角标：`15 / 15 → 3 / 15`

### 三级 · 一律砍掉

- 每段的副标题、导语、过渡句
- bullet 要点列表、四宫格、特性九宫格
- 「所以」「这意味着」「换句话说」
- 段尾小结、全片总结页的功能罗列
- 章节编号大字（`01` `02` 压在画面上，除了极简的段落索引外都不必要）
- 装饰性英文（`FEATURES` `OVERVIEW` `WHY US`）

## 禁用句式

这些句式是 AI 写文案的指纹，出现即视为文案不合格：

- 「不是……而是……」「不仅仅是……更是……」
- 「让我们一起……」「在这个时代……」「在当今……」
- 「赋能」「闭环」「抓手」「颗粒度」「心智」「范式」
- 「强大」「极致」「丝滑」「颠覆」「重新定义」
- 「无需 X，也能 Y」——除非真的对比，否则是凑排比
- 三段式排比（「更快、更稳、更自由」）
- 每句都以短句 + 句号结尾的节奏（读起来像产品页，不像人说话）

**替代做法**：把形容词换成事实。不写「极速渲染」，写「3600 帧 5 分钟渲完」；不写「极致丝滑」，写「拖拽时兄弟行一次跳一格」。

## 中文口语化

- 面向普通观众时避开术语：不写「指针」「句柄」「闭包」「幂等」，换成「引用」「标记」「记住上一次的结果」「重复执行也不会出错」
- 面向开发者时不要反过来解释常识：不必解释「什么是 Git」「什么是 JSON」
- 用「你」不用「用户」；用「本机」不用「本地环境」
- 具体名词优先于抽象名词：「任务列表」优于「数据视图」，「Worker」优于「执行容器」
- 用户偏好：解说词里把「AI」写成「大模型」（画面元素如 logo、图表上的 AI 字样保留，不要改动产品标识）

## 去 AI 味流程

写完文案不要直接进配音或进画。按这个顺序过一遍：

1. 通读，把每一句里能被删掉的修饰词划掉
2. 把「形容词」逐条换成「数字或动作」
3. 检查禁用句式
4. 自己念一遍：如果一句话念出来不像人会说，就重写
5. 再检查多音字（见下）

已安装 `humanizer-zh` 技能时，用它跑一遍再做人工复核，效果更稳。

## TTS 多音字规避

配音稿里出现多音字，TTS 有一半概率读错，而**读错比文案平淡更致命**。原则：**换词，不要标拼音**。

| 高频坑 | 容易读错成 | 改成 |
|---|---|---|
| 行（háng / xíng） | 「银行行」 | 表格行 → 「第 4 条」；行业 → 「领域」 |
| 重（chóng / zhòng） | 「重（zhòng）新」 | 重新 → 「再次」；重命名 → 「改名」 |
| 长（cháng / zhǎng） | 「生 zhǎng」 | 长按 → 「按住」；长度 → 保留（安全） |
| 还（hái / huán） | 「归 huán 是」 | 还是 → 「仍然」 |
| 便（biàn / pián） | 「方 biàn 宜」 | 方便 → 「容易」 |
| 得（dé / děi / de） | 「děi 到」 | 得到 → 「拿到」；必须 → 「必须」（安全） |
| 着（zhe / zháo / zhuó） | 「zhuó 手」 | 着手 → 「开始做」 |
| 调（tiáo / diào） | 「diào 整」 | 调整 → 「改」；调色 → 「配色」 |
| 数（shù / shǔ） | 「shǔ 据」 | 数据 → 保留前先试听（多数引擎正确） |
| 系（xì / jì） | 「关 jì」 | 关系 → 「关联」 |
| 载（zǎi / zài） | 「记 zài」 | 记载 → 「记录」；加载 → 保留 |
| 干（gān / gàn） | 「gàn 扰」 | 干扰 → 「影响」 |
| 差（chā / chà） | 「chà 异」 | 差异 → 「不同」 |
| 少（shǎo / shào） | 「多 shào」 | 多少 → 「几」 |
| 薄（báo / bó） | 「bó 片」 | 薄片 → 「片」 |

做法：先写完，再拿表逐条搜；命中的换成不歧义的表达。**不要**靠插入拼音字母或加空格强行纠正，`边缘情况`、`行（háng）` 这种标注会让配音出现奇怪停顿。

改完必须试听，尤其注意专有名词、英文缩写与中文混读的位置。

## 落版（最后一屏）

三行封顶，按这个顺序：

1. **一句结论**：状态 + 一句人话（`0.9.10 已发布`、`数据仍然只留在你的本机`）
2. **授权 / 价格**：`MIT 免费`、`可商用`
3. **入口**：带图标的 URL，等宽字体，弱化色

不要放：二维码、五个社交图标、Slogan 排比、感谢观看。
